# Claude Code 실전

Claude Code를 처음 쓰는 개발자와 팀 도입을 준비하는 리드를 위한 입문→실전 안내서입니다. 터미널의 첫 세션에서 시작해 코드베이스 탐색, 작업 계획, 문서화·테스트·리팩토링을 사람의 검토와 함께 진행하는 방법을 다룹니다.

## 대상 독자와 선수지식
- Claude Code를 처음 사용하는 개발자, 기존 프로젝트에 도입하려는 팀 리드
- 터미널·Git의 기본 사용법과 코드를 읽고 테스트를 실행할 수 있는 기초 개발 지식이 있으면 실습을 따라가기 좋습니다.

## 학습 경로와 결과물
- 입문: Claude Code 이해와 첫 세션, 권한 모드와 승인, CLAUDE.md 작성
- 활용: 슬래시 커맨드·서브에이전트·계획 모드, hooks·MCP·스킬
- 실전: 컨텍스트·장시간 작업·비용 관리, 팀 도입, CI/CD 연동, 트러블슈팅
- 만들어 볼 결과물: 모듈 README, 기존 스타일에 맞춘 테스트, 검토된 리팩토링 변경과 목적별 커밋

## 본문 속 실전 프로젝트
Part 6의 ‘코드베이스 문서화·테스트·리팩토링 자동화’에서는 기존 프로젝트를 탐색하고 계획한 뒤, 문서를 작성하고 테스트를 보강하며 리팩토링하는 5단계 흐름을 따라갑니다. 문서는 사람이 확인하고 테스트는 직접 실행하며, 마지막에는 전체 diff를 리뷰합니다. AI의 변경을 그대로 신뢰하거나 테스트 통과를 보장하지 않습니다.
