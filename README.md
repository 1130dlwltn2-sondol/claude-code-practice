# Claude Code 실전

Claude Code를 제대로 쓰는 방법을 처음부터 끝까지 다룬 실전서입니다.

Claude Code는 터미널에서 동작하는 AI 코딩 도구입니다. 코드를 대신 짜 주는 것을 넘어, 코드베이스를 탐색하고, 계획을 세우고, 여러 파일을 고치고, 테스트를 돌리는 일련의 과정을 스스로 수행합니다. 이 책은 설치와 첫 세션부터 CLAUDE.md 작성법, 슬래시 커맨드, 서브에이전트, 계획 모드, hooks, MCP 연동, 스킬, 컨텍스트 관리, 팀 도입과 CI/CD 연동까지 다룹니다.

책의 마지막에는 기존 코드베이스에 Claude Code를 도입해 문서화와 테스트 보강, 리팩토링을 자동화하는 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.

- 대상 독자: Claude Code를 처음 쓰는 개발자부터, 팀에 도입하려는 리드까지
- 기준일: 2026-10-09 (Claude Code는 업데이트가 빠르니 공식 문서를 함께 확인하세요)
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~6 본문 20개 장, 실전 프로젝트, 확인 문제, 마무리
- 저장소: https://github.com/1130dlwltn2-sondol/claude-code-practice
