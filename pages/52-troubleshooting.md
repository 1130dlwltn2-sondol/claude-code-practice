# 52. 트러블슈팅

자주 만나는 문제와 해결법입니다.

설치가 안 될 때: claude 명령을 찾을 수 없다는 메시지가 나오면 PATH 문제입니다. 설치 안내의 PATH 설정 부분을 확인합니다. 권한 오류가 나면 설치 명령의 권한을 확인합니다.

로그인이 안 될 때: 구독 계정과 API 키 중 어느 것으로 인증하는지 확인합니다. API 키를 쓴다면 환경 변수가 제대로 설정됐는지 봅니다. 회사 네트워크에서는 프록시 설정을 확인합니다.

세션이 이상하게 동작할 때: 같은 질문을 반복하거나 엉뚱한 파일을 고치면, 컨텍스트가 꼬였을 가능성이 큽니다. /compact로 정리하거나 새 세션을 시작합니다. CLAUDE.md가 오래돼서 현실과 다르면 그것도 원인입니다. 업데이트합니다.

권한 승인이 너무 자주 뜰 때: 허용 목록을 점검합니다. 안전한 반복 명령을 허용 목록에 넣습니다. 반대로 승인이 안 뜨고 위험한 짓을 했다면, 허용 목록에 너무 많은 것이 들어간 건 아닌지 봅니다.

느릴 때: 컨텍스트가 가득 찼거나, MCP 서버가 응답이 느리거나, 네트워크 문제일 수 있습니다. /compact, MCP 서버 점검, 네트워크 확인 순서로 봅니다.

공식 문서의 Troubleshooting 페이지를 북마크해 두세요. 업데이트가 빠른 도구라 최신 해결법은 문서가 가장 정확합니다.

핵심 정리
- 안 되면 PATH, 로그인, 컨텍스트 순서로 의심한다.
- /compact와 새 세션이 만능 해결책인 경우가 많다.
- 최신 해결법은 공식 문서의 Troubleshooting에서 확인한다.
