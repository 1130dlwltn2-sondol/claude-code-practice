# 51. CI/CD 연동

Claude Code는 CI/CD 파이프라인에서도 쓸 수 있습니다. 대표적으로 GitHub Actions와 연결해 PR 리뷰나 이슈 처리를 자동화합니다.

PR 자동 리뷰가 가장 흔한 용도입니다. PR이 열리면 Claude Code가 변경 사항을 읽고 리뷰 코멘트를 답니다. 사람이 보기 전에 obvious한 문제를 잡아줍니다. 다만 AI 리뷰를 맹신하지는 않습니다. "참고용 1차 리뷰"로 두고, 최종 판단은 사람이 합니다.

이슈 자동 처리도 가능합니다. 이슈에 특정 라벨이 붙으면 Claude Code가 브랜치를 파고 수정한 뒤 PR을 여는 흐름입니다. 간단한 버그 수정이나 의존성 업데이트 같은 정형 작업에 적합합니다. 중요한 변경은 사람이 승인해야 머지되게 둡니다.

CI에서 쓸 때의 주의점입니다. 권한을 최소로 줍니다. CI용 토큰은 필요한 저장소에만 접근하게 합니다. 비용도 봅니다. PR마다 무거운 작업을 돌리면 요금이 늘어납니다. 언제 실행할지 조건을 겁니다. 예를 들어 특정 라벨이 있을 때만 실행하는 식입니다.

실습: PR 리뷰 워크플로우
1. GitHub Actions에 Claude Code 리뷰 스텝 추가하기
2. 테스트 PR을 열어 리뷰 코멘트가 달리는지 확인하기

핵심 정리
- PR 자동 리뷰와 이슈 자동 처리가 대표 용도다.
- AI 리뷰는 참고용으로 두고 최종 판단은 사람이 한다.
- CI 토큰 권한은 최소로, 실행 조건을 걸어 비용을 관리한다.
