정답과 해설
1. 나 - 터미널 CLI가 중심이고, VS Code와 데스크톱, 웹으로도 쓸 수 있다.
2. 나 - Claude 구독 계정이나 Anthropic API 키로 인증한다.
3. 나 - 모르는 작업이나 위험한 작업은 승인 요청이 뜬다.
4. 나 - CLAUDE.md는 세션 시작 시 읽히는 프로젝트 설명서다.
5. 나 - /compact는 대화를 요약해 컨텍스트를 비운다.
6. 가 - .claude/commands 폴더에 마크다운 파일로 만든다.
7. 나 - 병렬 처리로 빨라지고 컨텍스트가 분리된다.
8. 가 - 계획 모드는 실행 전에 계획을 세우고 검토한다.
9. 나 - hooks는 특정 시점에 자동 실행되는 스크립트다.
10. 가 - MCP는 AI가 외부 도구를 쓰는 공개 표준이다.
11. 가 - claude mcp add 명령으로 MCP 서버를 추가한다.
12. 나 - 스킬은 필요할 때 꺼내 쓰는 전문 지식 묶음이다.
13. 나 - /compact나 새 세션으로 정리하는 것이 답이다.
14. 나 - 마일스톤으로 나누고 중간에 확인하면 방향이 틀어져도 일찍 잡는다.
15. 가 - PR 자동 리뷰가 대표 용도이며 최종 판단은 사람이 한다.
16. 나 - CI 토큰은 필요한 범위의 최소 권한으로 준다.
17. 가 - 명령을 찾지 못하면 PATH 설정을 확인한다.
18. 나 - 컨텍스트가 꼬였을 가능성이 크니 /compact나 새 세션을 쓴다.
19. 다 - 개인 API 키 같은 비밀값은 공유하지 않는다.
20. 나 - AI가 짠 코드는 반드시 사람이 리뷰한다.
