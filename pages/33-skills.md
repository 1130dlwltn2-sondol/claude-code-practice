# 33. 스킬

스킬은 특정 작업을 위한 지식 묶음입니다. Claude Code에게 "이렇게 일해"라고 가르치는 방법 중 하나입니다. 예를 들어 "우리 팀의 API 설계 규칙" 스킬을 만들어 두면, API를 만들 때마다 그 규칙을 따라갑니다.

스킬과 CLAUDE.md의 차이입니다. CLAUDE.md는 항상 읽히는 기본 설명서이고, 스킬은 필요할 때 꺼내 쓰는 전문 지식입니다. 자주 쓰는 핵심 규칙은 CLAUDE.md에, 특정 작업에만 필요한 깊은 지식은 스킬로 나눕니다. 이렇게 하면 평소 컨텍스트를 아낄 수 있습니다.

스킬은 마크다운 파일로 만듭니다. 작업 절차, 예제, 주의사항을 적습니다. 예를 들어 "DB 마이그레이션 스킬"에는 마이그레이션 파일 작성 규칙, 테스트 방법, 롤백 절차를 적습니다. 관련 작업이 오면 Claude Code가 스킬을 읽고 그 절차를 따릅니다.

팀에서 스킬을 공유하면 작업 품질이 균일해집니다. 신입이 와도 스킬만 읽히면 팀의 방식으로 일합니다. 스킬은 코드처럼 리뷰하고 버전 관리합니다. 규칙이 바뀌면 스킬을 고치고, 바뀐 이유를 남깁니다.

실습: 스킬 만들기
1. 자주 반복하는 작업 하나를 정하기
2. 절차와 예제를 담은 스킬 파일 작성하기
3. 관련 작업을 맡겨 스킬이 적용되는지 확인하기

핵심 정리
- 스킬은 필요할 때 꺼내 쓰는 전문 지식 묶음이다.
- 기본 규칙은 CLAUDE.md에, 깊은 지식은 스킬로 나눈다.
- 팀 공유 스킬은 코드처럼 리뷰하고 관리한다.
