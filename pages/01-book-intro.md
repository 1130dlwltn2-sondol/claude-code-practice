# 책 소개

이 책은 Claude Code를 제대로 쓰는 방법을 다룬 실전서입니다. Claude Code는 터미널에서 동작하는 AI 코딩 도구로, 단순히 코드를 제안하는 수준을 넘어 코드베이스 전체를 이해하고 작업을 끝까지 수행합니다. 파일을 읽고, 계획을 세우고, 코드를 고치고, 테스트를 돌리고, 커밋까지 이어지는 과정을 스스로 진행합니다.

많은 사람이 Claude Code를 "질문하면 답하는 챗봇"처럼 씁니다. 하지만 이 도구의 진짜 힘은 일을 맡기는 데 있습니다. "이 버그를 고쳐줘"라고 말하면 관련 파일을 찾아 원인을 파악하고 수정한 뒤 테스트로 검증합니다. "이 기능을 추가해줘"라고 하면 기존 코드의 패턴을 따라 구현합니다. 어떻게 지시하고, 어떻게 환경을 갖춰 주느냐에 따라 결과물의 품질이 크게 달라집니다.

책의 구성은 다음과 같습니다. Part 1에서는 Claude Code가 무엇인지, 어떻게 설치하고 첫 세션을 시작하는지, 권한 모드와 승인이 어떻게 동작하는지 다룹니다. Part 2에서는 CLAUDE.md 작성법, 슬래시 커맨드, 서브에이전트 같은 효율적인 사용법을 익힙니다. Part 3에서는 계획 모드, hooks, MCP 연동, 스킬 같은 심화 기능을 다룹니다. Part 4에서는 컨텍스트 관리와 장시간 작업, 비용 관리 방법을 배웁니다. Part 5에서는 팀 공유 설정과 CI/CD 연동, 트러블슈팅을 다룹니다. Part 6은 실전 프로젝트로, 기존 코드베이스에 Claude Code를 도입해 문서화와 테스트 보강, 리팩토링을 자동화하는 과정을 처음부터 끝까지 따라 합니다.

각 장은 개념 설명, 따라 하기 실습, 핵심 정리로 구성됩니다. 실습은 자신의 컴퓨터에 Claude Code를 설치하고 진행하면 됩니다. Claude 구독이나 Anthropic API 계정이 필요합니다.

이 책을 다 읽고 나면, Claude Code에게 일을 맡기고 검증하는 개발 방식을 갖추게 됩니다.
