# 21. 슬래시 커맨드

슬래시 커맨드는 /로 시작하는 단축 명령입니다. 자주 쓰는 작업을 한 단어로 실행합니다. /compact는 대화를 요약해 컨텍스트를 비우고, /clear는 대화를 새로 시작합니다. /help로 전체 목록을 볼 수 있습니다.

커스텀 커맨드는 직접 만들 수 있습니다. .claude/commands 폴더에 마크다운 파일을 놓으면 됩니다. 예를 들어 review.md를 만들고 "바뀐 코드를 리뷰하고 문제점을 지적해줘"라는 지시를 적어 두면, /review로 실행됩니다. 인자를 받을 수도 있습니다. /review src/auth 처럼 대상을 지정하는 식입니다.

커스텀 커맨드가 빛나는 곳은 반복 작업입니다. PR 설명 생성, 변경 사항 요약, 테스트 실행과 결과 정리 같은 일을 커맨드로 만들어 두면 매번 길게 지시하지 않아도 됩니다. 팀원들과 공유하면 팀 전체의 작업 방식이 통일됩니다.

커맨드를 설계할 때의 요령입니다. 하나의 커맨드는 하나의 일을 합니다. 지시는 구체적으로 씁니다. "잘해줘"가 아니라 "세 가지를 확인해줘: 1) 에러 처리, 2) 테스트 커버리지, 3) 네이밍" 같은 식입니다. 출력 형식도 정해 두면 결과가 일정해집니다.

실습: 커스텀 커맨드
1. .claude/commands/review.md 만들기
2. 코드 리뷰 지시를 구체적으로 작성하기
3. /review로 실행해 보기

핵심 정리
- 슬래시 커맨드는 자주 쓰는 작업을 단축 실행한다.
- .claude/commands에 마크다운으로 커스텀 커맨드를 만든다.
- 반복 작업일수록 커맨드로 만들어 두는 것이 이득이다.
