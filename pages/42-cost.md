# 42. 비용 관리

Claude Code를 많이 쓰면 비용이 신경 쓰입니다. 구독제와 API 과금 중 무엇이 유리한지는 사용 패턴에 따라 다릅니다.

구독제는 정액이라 마음 편히 쓸 수 있습니다. 다만 사용량 제한이 있어서, 한도를 넘기면 느려지거나 멈춥니다. API 과금은 쓴 만큼 내는 방식이라 한도는 넉넉하지만, 큰 작업을 돌리면 요금이 늘어납니다. 가볍게 자주 쓰면 구독제, 무겁게 몰아서 쓰면 API 과금을 비교해 보세요.

비용을 줄이는 실무 요령입니다. 첫째, 탐색은 가볍게 합니다. "전체를 읽어줘" 같은 지시는 토큰을 많이 씁니다. 범위를 좁힙니다. 둘째, 작은 작업에는 작은 모델을 씁니다. 단순한 수정이나 요약은 가벼운 모델로도 충분합니다. 셋째, 반복 작업을 줄입니다. 같은 실수를 반복하면 토큰이 샙니다. CLAUDE.md와 스킬을 잘 갖춰 두면 첫 시도에 성공할 확률이 올라갑니다.

팀으로 쓸 때는 개인별 사용량을 봅니다. 누가 어디에 많이 쓰는지 파악되면, 비효율적인 패턴을 찾아 고칠 수 있습니다. 예를 들어 매번 전체 테스트를 돌리는 세션이 있다면, 관련 테스트만 돌리도록 지침을 바꿉니다.

핵심 정리
- 가볍게 자주 쓰면 구독제, 무겁게 몰아서 쓰면 API 과금을 비교한다.
- 탐색 범위를 좁히고 작은 작업엔 작은 모델을 쓴다.
- CLAUDE.md와 스킬 정비가 곧 비용 절감이다.
