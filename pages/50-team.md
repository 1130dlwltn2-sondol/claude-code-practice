# Part 5. 팀과 운영

## 50. 팀 공유 설정

팀에서 Claude Code를 쓰면 설정을 공유하는 것이 출발점입니다. CLAUDE.md, 커스텀 커맨드, 서브에이전트, hooks 설정을 저장소에 넣어 함께 관리합니다. 새 팀원이 와도 같은 환경에서 시작합니다.

공유할 것과 공유하지 않을 것을 구분합니다. 공유하는 것: 프로젝트 규칙, 커맨드, 스킬, hooks입니다. 공유하지 않는 것: 개인 API 키, 개인별 허용 목록입니다. 비밀값은 각자의 환경에 둡니다.

팀 규칙 문서도 만듭니다. 언제 Claude Code를 쓰고 언제 직접 하는지, AI가 만든 코드는 어떻게 리뷰하는지 정합니다. 예를 들어 "AI가 짠 코드는 반드시 사람이 리뷰한다", "테스트 없이 머지하지 않는다" 같은 원칙입니다. 도구가 좋아도 프로세스가 없으면 품질이 흔들립니다.

정기적으로 설정을 다듬습니다. 팀원이 만든 좋은 커맨드나 스킬이 있으면 공유 저장소에 올립니다. 안 쓰는 것은 지웁니다. 설정도 코드처럼 리뷰합니다.

핵심 정리
- CLAUDE.md, 커맨드, 스킬, hooks는 저장소에 넣어 공유한다.
- 비밀값은 공유하지 않고 각자 관리한다.
- AI 코드 리뷰 원칙 같은 팀 규칙을 문서로 정한다.
