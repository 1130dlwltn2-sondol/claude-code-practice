# Part 1. Claude Code 시작하기

## 10. Claude Code란 무엇인가

Claude Code는 Anthropic이 만든 AI 코딩 도구입니다. 터미널에서 실행되는 CLI가 중심이고, VS Code 확장, 데스크톱 앱, 웹, JetBrains 플러그인으로도 쓸 수 있습니다. 어느 화면에서 쓰든 같은 엔진을 공유해서, 저장소의 CLAUDE.md나 MCP 설정이 그대로 이어집니다.

일반적인 코드 어시스턴트와 다른 점은 에이전트라는 것입니다. 코드를 한 줄씩 제안하는 게 아니라, 목표를 주면 스스로 작업을 수행합니다. 예를 들어 버그 리포트를 주면 관련 파일을 찾아 읽고, 원인을 파악하고, 수정하고, 테스트를 돌려 검증합니다. 필요하면 여러 파일을 동시에 고치고, 커밋 메시지까지 작성합니다. 개발자가 하는 일의 단위가 "줄"이 아니라 "작업"인 셈입니다.

설치는 운영체제별로 방법이 있습니다. macOS와 Linux, WSL에서는 네이티브 설치 명령을 쓰고, Homebrew나 WinGet으로도 설치할 수 있습니다. 설치가 끝나면 claude --version으로 버전을 확인합니다. 처음 실행하면 로그인을 묻는데, Claude 구독 계정이나 Anthropic API 키로 인증합니다.

요금은 쓰는 방식에 따라 다릅니다. 구독제로 쓰면 정액, API 키로 쓰면 토큰 사용량에 따라 과금됩니다. 장시간 작업을 많이 돌린다면 어느 쪽이 유리한지 따져 보세요. 비용 관리는 Part 4에서 자세히 다룹니다.

핵심 정리
- Claude Code는 작업을 끝까지 수행하는 에이전트형 코딩 도구다.
- 터미널 CLI가 중심이고 VS Code, 데스크톱, 웹으로도 쓸 수 있다.
- 처음 실행 시 Claude 구독이나 API 키로 로그인한다.
