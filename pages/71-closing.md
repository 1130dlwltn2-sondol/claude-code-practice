# 71. 마무리

이 책에서는 Claude Code의 설치와 첫 세션부터 권한 관리, CLAUDE.md, 슬래시 커맨드, 서브에이전트, 계획 모드, hooks, MCP 연동, 스킬, 컨텍스트 관리, 장시간 작업, 비용 관리, 팀 도입, CI/CD 연동, 트러블슈팅, 그리고 실전 프로젝트까지 다뤘습니다.

Claude Code를 잘 쓰는 핵심은 한 문장으로 정리됩니다. 일을 작게 나누어 맡기고, 결과를 검증하는 것입니다. 목표를 분명히 말하고, 제약을 함께 주고, 검증 방법을 정합니다. 방향이 틀리면 멈추고 바로잡습니다. 이 리듬이 몸에 배면, Claude Code는 단순한 도구를 넘어 일하는 방식 자체를 바꿉니다.

Claude Code는 빠르게 바뀌는 도구입니다. 새 기능이 나오면 공식 문서를 확인하고, 이 책의 방법이 낡았다면 문서의 방법이 정답입니다. 커뮤니티에서 다른 사람들의 활용법을 보는 것도 좋습니다.
