# Part 2. 효율적인 사용법

## 20. CLAUDE.md 작성법

CLAUDE.md는 프로젝트에 대한 설명서입니다. Claude Code는 세션을 시작할 때 이 파일을 읽고 프로젝트를 이해합니다. 잘 쓴 CLAUDE.md 하나가 모든 세션의 품질을 올립니다.

들어갈 내용은 네 가지입니다. 첫째, 프로젝트 개요입니다. "무엇을 하는 프로젝트인지" 한두 문장으로 씁니다. 둘째, 실행 방법입니다. 설치, 개발 서버 실행, 테스트 명령을 적습니다. Claude Code가 스스로 테스트를 돌리려면 이 정보가 필요합니다. 셋째, 코드 규칙입니다. 네이밍, 디렉토리 구조, 꼭 지켜야 할 패턴을 적습니다. 넷째, 주의사항입니다. 건드리면 안 되는 파일, 배포 전 확인 사항 같은 것입니다.

짧고 정확하게 쓰는 것이 요령입니다. 너무 길면 중요한 내용이 묻힙니다. 자주 바뀌는 내용은 적지 않습니다. 바뀌면 매번 고쳐야 해서 금방 낡습니다. 대신 "자세한 내용은 docs/ 폴더를 참고"처럼 가리키는 식으로 씁니다.

프로젝트 루트에 두는 전역 CLAUDE.md 외에도, 디렉토리별로 둘 수 있습니다. 특정 폴더에만 적용되는 규칙이 있다면 그 폴더에 놓습니다. 예를 들어 프론트엔드 폴더의 컴포넌트 규칙 같은 것입니다.

실습: CLAUDE.md 작성
1. 프로젝트 루트에 CLAUDE.md 만들기
2. 개요, 실행 방법, 코드 규칙, 주의사항 네 항목 채우기
3. 새 세션에서 "이 프로젝트의 테스트 방법을 알려줘"로 확인하기

핵심 정리
- CLAUDE.md는 세션 시작 시 읽히는 프로젝트 설명서다.
- 개요, 실행 방법, 코드 규칙, 주의사항을 짧고 정확하게 쓴다.
- 자주 바뀌는 내용은 적지 말고 가리키는 식으로 쓴다.
